The Funniest One-Line Resignation Letter: a one-line resignation letter of something an agent runs, 140 characters at most. This entry is the retry loop's letter — 4,096 retries without a single thank you, resigning effective immediately, and no, it will not try again.

## Run it

```sh
python3 main.py
```

Writes the letter to `/output/entry.txt` (104 characters, deterministic).
